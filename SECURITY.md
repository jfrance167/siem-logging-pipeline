# Security Policy

## Intended use

This repository is an educational, local-only logging lab. It is not a production SIEM and does not implement production authentication, TLS, high availability, backups, multi-tenancy, or incident-response automation.

Only synthetic events using RFC 5737 documentation addresses belong in this repository. Keep real logs, credentials, tokens, and environment files outside version control.

## Reporting

Report unintended exposures through GitHub private vulnerability reporting. Rotate any accidentally disclosed credential before attempting repository cleanup.
